How to start video analysis

In the Python terminal, run python detector.py --source 0 for webcam or python detector.py --source "C:\path\video.mp4" for a recorded video. Press q in the video window to stop.

The restricted rectangle is configured in python-ai/detector.py. Fire/smoke and weapon alerts require compatible custom models. Face recognition is a separate opt-in demo.

Educational prototype only. Alerts can be wrong; verify events manually.
